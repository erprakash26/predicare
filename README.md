## 🌟 Overview

PrediCareAI is an innovative AI-powered remote monitoring platform designed to predict risks, detect anomalies, and support seniors living independently.  
By integrating wearable sensors, home monitoring devices, and predictive analytics, PrediCareAI provides **real-time insights**, **fall detection**, and **health risk forecasts**, empowering caregivers with proactive alerts.

---

## 🩺 Key Features

### **Continuous Monitoring**
- Tracks heart rate, steps, and activity levels  
- Detects falls via a wearable wrist sensor  
- Medication reminders & adherence tracking  

### **Predictive AI**
- Identifies unusual behavior patterns  
- Forecasts fall or health risks  
- Notifies caregivers before emergencies happen  

### **Caregiver Dashboard**
- Real-time vitals  
- Live monitoring dashboard
- Risk assessments & anomaly alerts  

### **Voice Companion**
- Provides reminders  
- Helps reduce missed medication  
- Offers daily emotional support
